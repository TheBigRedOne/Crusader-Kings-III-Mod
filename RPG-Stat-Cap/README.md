# RPG Stat Caps

为《Crusader Kings III》的角色扮演与控制台存档提供最终数值硬上限，避免各类增益不断叠加后把游戏数值推到失去意义的水平。

当前 `1.0` 版本限制玩家角色的最终骑士战斗力（Knight Effectiveness）。模组读取游戏计算完成后的最终数值，只抵消超过上限的部分，不会削弱或覆盖各项原始增益来源。

## 支持版本

- Crusader Kings III `1.19.x (Scribe)`
- 已在 `1.19.0.6` 的现有模组存档中验证
- English (United Kingdom) 与简体中文（中国大陆）
- 单人游戏

模组使用一个与 CK3 1.19.x 原版内容一致的 `gui/shared/sounds.gui`。游戏更新后，如果该原版文件发生变化，需要重新核对并更新模组内的副本。

## 下载

从本仓库的 Releases 页面下载 `RPG Stat Caps 1.0` 压缩包，或在 Steam Workshop 页面订阅本模组。

本地安装时：

1. 在 CK3 用户目录的 `mod` 文件夹内创建 `RPG_Stat_Caps` 文件夹。
2. 把发布包内的模组文件复制到该文件夹。
3. 把 `RPG_Stat_Caps.mod` 复制到上一级 `mod` 文件夹。
4. 在 CK3 启动器的播放集内启用 **RPG Stat Caps**。

Windows 默认用户目录为：

```text
Documents/Paradox Interactive/Crusader Kings III/mod/
```

## 使用方法

1. 打开游戏的“决议”窗口。
2. 选择“配置 RPG 数值上限”。
3. 选择 `150%`、`200%`、`250%`、`300%` 或 `400%`，继续并确认。
4. 最终骑士战斗力会在约两秒内完成校正，游戏暂停时同样生效。
5. 如需关闭模组修正，选择“骑士战斗力：不设上限”。

所选上限作为战役设置保存在存档中，并在继承或切换玩家角色后继续生效。模组仅影响玩家角色，AI 领地不受影响。

## 已验证行为

- 四位数百分比的最终骑士战斗力可以动态限制到所选上限。
- 特质、宝物、建筑、勋号、事件、控制台工具和其他模组仍可继续改变自然总值。
- 自然总值低于或等于上限时，不会添加正面修正把数值强行提高到上限。
- 自然总值后来降到上限以下时，旧的负面修正会被移除，使角色恢复到自然数值。
- 游戏暂停时仍会完成检测和校正。
- 已经符合规定值时，后续批处理不会重复移除或添加修正。
- 修正缺失、修正量不符或最终值未落在规定值时，下一轮会自动重试。
- 现有存档和角色继承场景已经过实际加载验证。

## 工作原理

模组读取玩家角色已经包含全部来源影响的最终骑士战斗力，并还原本模组上一次施加抵消修正前的自然总值。

如果自然总值超过上限，模组添加一个只抵消超额部分的负面修正；如果自然总值低于或等于上限，则不添加任何正面修正。

一个不可见的界面计时器每两秒调用一次统一批处理入口。每轮计算使用临时变量；只有在以下情况下才会更新持久修正：

- 首次发现自然总值超过上限；
- 自然总值或所选上限发生变化；
- 修正缺失、修正量不符或最终值没有落在所选上限；
- 自然总值降到上限以下，需要移除旧修正。

当已保存的修正量和最终值都符合设定时，本轮检测保持只读，不会重建修正。以后增加其他数值上限时，可以继续加入同一个批处理入口，而不需要为每项数值建立独立计时器。

## 安全与故障处理

- 模组不使用 `replace_path`，也不覆盖特质、建筑、生活方式、宝物、勋号或其他玩法数据库。
- 为了在暂停状态下执行动态检测，模组覆盖 `gui/shared/sounds.gui`，同时保留 CK3 1.19.x 的原版内容。
- 任何同样覆盖 `gui/shared/sounds.gui` 的界面模组或大型转换模组都需要兼容补丁。只调整加载顺序不能同时保留双方改动。
- 当前验证场景为 CK3 单人游戏。
- 如需移除模组，先选择“不设上限”，等待至少两秒，保存游戏，然后再在启动器中停用模组。

## 文件

- `common/decisions/`：游戏内配置决议
- `common/modifiers/`：骑士战斗力抵消修正
- `common/script_values/`：动态修正量
- `common/scripted_guis/`：统一批处理与校验逻辑
- `gui/shared/sounds.gui`：暂停状态下仍可运行的不可见计时器
- `localization/`：English (United Kingdom) 与简体中文（中国大陆）文本；目录名是 CK3 规定的固定拼写
- `descriptor.mod`：Steam Workshop 模组描述文件
- `RPG_Stat_Caps.mod`：本地启动器描述文件
- `WORKSHOP.md`：Steam Workshop 双语发布文案
- `SHA256SUMS.txt`：正式模组文件的 SHA-256
- `COPYRIGHT.md`：使用与版权范围
