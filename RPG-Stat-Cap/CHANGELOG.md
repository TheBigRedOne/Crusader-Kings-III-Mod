# Changelog

## 1.0

- First public release.
- Added a player-only hard cap for final Knight Effectiveness.
- Added 150%, 200%, 250%, 300%, 400%, and disabled presets.
- Added automatic recalculation after modifier changes and succession.
- Added one shared batch entry point with temporary per-pulse calculations.
- Rewrites the persistent correction only when the required or displayed value
  is no longer correct.
- Retries missing or partially applied corrections automatically.
- Never adds a positive modifier to raise an under-cap value.
- Added English (United Kingdom) and Simplified Chinese (Mainland China)
  localisation.
